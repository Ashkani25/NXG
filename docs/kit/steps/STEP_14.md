# STEP_14 — PERSONAL ORBIT — فضای شخصی

## ورودی (آنچه باید از قبل آماده باشد)
آواتار (STEP_09)، پیشرفت (STEP_13)، Hub (STEP_11)، پارامتر P22 برای local-first.
قبل از شروع `docs/HANDOFF.md` را بخوان و مطمئن شو معیار پذیرش مرحله قبل برقرار است.

## هدف
ساخت خانه اختصاصی کاربر در NEXORA.

## دستورالعمل‌ها
1. صحنه Personal Orbit: محیطی (کپسول/اتاق مداری) که آواتار کاربر در آن حضور دارد.
2. بخش‌ها: پروفایل، Explorer ID، دوستان، سطح و XP، دستاوردها، فعالیت‌ها، آیتم‌های شخصی، تنظیمات سریع.
3. شخصی‌سازی محیط: انتخاب تم، دکور، افکت‌ها از آیتم‌های مالک‌شده؛ چیدمان ذخیره‌شونده (`orbit_layout`).
4. نمایش پروفایل عمومی دیگران با همان UI (حالت بازدیدکننده).
5. لایه local-first: Drift/Isar برای cache پروفایل و تنظیمات و صف sync آفلاین.
6. پیوند به دنیاهای دیگر: نمایش آخرین فعالیت بازی/پست/اجتماع به‌صورت کارت.

## تأکید گرافیک و معماری
حس مالکیت با جزئیات بصری: نور اختصاصی، حرکت آرام اشیا، انتقال دوربین هنگام باز شدن بخش‌ها. حالت 2D لیست‌محور برای کیفیت پایین.
