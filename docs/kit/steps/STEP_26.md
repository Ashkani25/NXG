# STEP_26 — SOCIAL STATION — اجتماعات

> مرحله 26 از ۳۰ | قبلی: [STEP_25 — NOVA GALLERY — شبکه اجتماعی](STEP_25.md) | بعدی: [STEP_27 — ORACLE CORE — دستیار هوشمند](STEP_27.md)

## ورودی (آنچه باید از قبل آماده باشد)
چت (STEP_23)، Nova Gallery (STEP_25)، مسابقه (STEP_22)، دوستی و دعوت (STEP_15).
قبل از شروع `docs/HANDOFF.md` را بخوان و مطمئن شو معیار پذیرش مرحله قبل برقرار است.

## هدف
ساخت Community با گروه‌ها، رویداد و مدیریت.

## دستورالعمل‌ها
1. جدول‌ها: `communities`، `community_members`، `roles`، `events`، `community_rules`.
2. ساخت Community عمومی/خصوصی/موضوعی/بازی/مسابقه با دسته‌بندی و جستجو.
3. نقش‌ها: مالک، مدیر، ناظر، عضو؛ مجوزهای دقیق؛ مدیریت درخواست عضویت و اخراج.
4. رویدادها (زمان‌بندی، یادآوری، شرکت) و **برگزاری مسابقه اختصاصی جامعه** با API STEP_22.
5. اتاق چت جامعه (ارتباط با Orbit Network) و فید جامعه (ارتباط با Nova Gallery).
6. اعلان‌های اجتماعی و دعوت دوستان.

## تأکید گرافیک و معماری
ایستگاه اجتماعی به‌صورت فضای گردهمایی گرافیکی: کارت‌های بزرگ جوامع، نشان جامعه، صحنه رویداد. همان زبان طراحی با تم گرم‌تر و اجتماعی.
